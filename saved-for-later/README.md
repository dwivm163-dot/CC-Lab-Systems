# Saved for Later

An interactive data self-portrait built from Mannat Dwivedi’s exported
Pinterest data. The project explores the gap between a saved, aspirational
self and everyday reality.

## Files

- `index.html` — landing page
- `appearance.html` — Appearance collage
- `making.html` — blank Making collage workspace
- `living.html` — blank Living collage workspace
- `styles.css` — all site and collage styles
- `public/collages/appearance/` — Appearance image assets

## Run locally

```bash
npm install
npm run dev -- --port 43127
```

Open [http://localhost:43127](http://localhost:43127).

## Build

```bash
npm run build
```

The project uses standard HTML and CSS with Vite as the local development
server and production bundler.
